# M1 Q5 - LEE

A Three.js scene showcasing five animated 3D geometries.

## Geometries
- BoxGeometry (red)
- ConeGeometry (cyan)
- CylinderGeometry (green)
- SphereGeometry (gold)
- TorusGeometry (purple)

## How to Run
Open `index.html` in a browser, or visit the GitHub Pages link below.
